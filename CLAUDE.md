# Project context

Before changing anything, read in this order:

1. `docs/PRD.md` (what and why)
2. `docs/ARCHITECTURE.md` (how)
3. `docs/DESIGN.md` (look and feel)
4. `docs/RULES.md` (how to code here)
5. `TASKS.md` (what is next) and `docs/MEMORY.md` (current state)
6. `docs/SECURITY.md`, `docs/TEST_PLAN.md`, `docs/DECISIONS.md` when relevant

Work one task at a time: read → plan → implement → test → review → commit → update
`TASKS.md` / `docs/MEMORY.md` / `docs/DECISIONS.md`.

Commands: `npm run dev`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.
